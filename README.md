# Jackson's Portfolio Website

A modern personal portfolio website built with HTML, CSS, and JavaScript. It showcases the developer's profile, projects, technical skills, CV download section, and contact details.

## Features

- Responsive personal portfolio landing page
- About section with skills and experience highlights
- Projects showcase cards
- CV download button
- Contact form and social links
- Mobile-friendly navigation

## Project Structure

- `index.html` — main page structure
- `styles.css` — site styling and layout
- `script.js` — interactive behavior such as menu toggling and effects
- `images/` — profile and portfolio images

## Run locally

1. Open the project folder in your editor.
2. Start a simple local server from the project root, for example:

```bash
python -m http.server 8000
```

3. Open your browser and visit:

```text
http://localhost:8000
```

You can also open `index.html` directly in a browser, though a local server is recommended for the best experience.

## Customize

Update the content in `index.html` to change:

- your name and title
- project descriptions
- social media links
- email and contact information
- CV file name and link

## Notes

The site currently references a CV file named `cv.pdf`. Add your own CV file in the project root if you want the download button to work.
